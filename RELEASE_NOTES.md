# Skywright v1.0

Skywright is a one-thumb arcade game in which every flap sends a pulse to cut the next paper wall. Pick your doorway height, then fly through it.

## Install

Download `Skywright-v1.0.apk` from the assets below, open it on an Android phone running Android 8.0 or newer, and allow installation from your browser or file manager if prompted. The game plays offline and asks for no runtime permissions.
