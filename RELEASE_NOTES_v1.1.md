# Skywright v1.1 — Dawn

The glowing band on each wall now has a purpose: it is the only place your pulse can cut. A miss flashes red and leaves that wall intact, so you can quickly realign and try again. A successful cut makes a fixed doorway that you still have to fly through.

The sky now moves through a full sunrise over five minutes of active play. The sun's height is your progress toward a **DAYBREAK** win. Walls accelerate as the sun rises, and newly spawned walls have smaller breakable bands and doorways. A wall's dimensions stay fixed once it appears, so the target never shrinks while your pulse is in flight. A collision ends the run; reaching sunrise requires one continuous survival run.

## Install

Download `Skywright-v1.1.apk` from this release on an Android 8.0 or newer phone, then open it. If Android asks, allow installation from the app you used to open the file. The game works offline. This APK is signed with the same key as v1.0 and can update an existing installation.
